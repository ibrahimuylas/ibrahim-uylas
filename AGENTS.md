# Project guidance

## Blog article workflow

When a request asks to create, adapt, translate, or package a blog article from a source link, or refers to the project's blog template, read and follow `.agents/skills/blog-yazisi/SKILL.md`.

When a blog article contains a table, also read and follow `.agents/skills/blog-tablosu/SKILL.md`. Never leave a bare Markdown table in an article; wrap it with the site's responsive `comparison-table` container.

Treat an explicit `$blog-yazisi` mention as mandatory. Never invent İbrahim's personal experiences or link to unpublished posts.

When a request asks to create, edit, crop, or package a blog banner, read and follow `.agents/skills/banner-olusturma/SKILL.md`. Keep banner source images intact and preserve their natural aspect ratio in the site hero render.
