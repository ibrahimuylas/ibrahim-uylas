# Spec 039 — Index Western official pafta context

**Status:** Completed  
**Priority:** P0 — primary-source intake  
**Depends on:** Spec 038  
**Scope:** Internal primary-source index; no current-condition or route publication

## Goal

Extend the bounded Ministry-detail source index to four Western paftas while preserving the rule that undated descriptive content cannot become current route advice.

## Indexed sources

- Pafta 3: Alınca–Sidyma–Gey-Bel
- Pafta 4: Belceğiz–Gavurağılı–Karadere
- Pafta 7: Akbel–Patara
- Pafta 10: Dereköy–Çukurbağ

## Review value

The source records identify places where the descriptive scope and the official pafta title may differ. They provide prompts for manual map comparison of endpoints, direction and variants, not a positive GPS verification.

## Rules and acceptance criteria

- [x] Each source is registered as link-only official route context with its access date.
- [x] All four observations prohibit use as current service, condition, metric or publication evidence.
- [x] No external GPS candidate is promoted and no public route content changes.
