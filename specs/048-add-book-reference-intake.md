# Spec 048 — Add book reference intake

**Status:** Completed  
**Priority:** P1 — secondary-source workflow  
**Depends on:** Spec 047  
**Scope:** Internal reference intake; no public route release

## Outcome

The guide can now accept page-specific information from a hiking book without copying its text or map material. A valid record requires a registered book source, edition, page reference, short paraphrase, pafta association, editor and `citation-only` rights status.

## Acceptance criteria

- [x] Book notes may support route-context, boundary, direction, variant and historical review work.
- [x] Book notes cannot create metrics, current operational facts or publication eligibility.
- [x] Direct quotations are rejected in favour of short paraphrases.
- [x] A maintainer form and an intake report make the required contribution format explicit.
