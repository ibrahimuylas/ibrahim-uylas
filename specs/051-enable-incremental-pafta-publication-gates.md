# Spec 051 — Enable incremental pafta publication gates

**Status:** Completed  
**Priority:** P0 — progressive release  
**Depends on:** Spec 050  
**Scope:** Internal release decisioning; no currently eligible pafta is published

## Outcome

Each official pafta can now be evaluated for publication independently of the all-route guide. A pafta needs official context, a verified official-match review, eligible source/right-cleared stage evidence and an editorially reviewed page record. The canonical full-route guide remains separately gated.

## Acceptance criteria

- [x] One fully evidenced pafta can become ready without satisfying all 31-pafta release requirements.
- [x] Partial, candidate or historical evidence keeps the pafta on hold.
- [x] The decision report names the missing requirements for every pafta.
- [x] No current pafta is made public by adding the gate.
