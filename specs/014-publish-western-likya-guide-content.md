# Publish the Western Likya guide content package

**Type:** Content package

**Priority:** P1 — first third of the full-route guide and likely source of several short plans

**Risk:** High

## Goal

Research, author and connect every official route section in the Western editorial region using the shared source model and stage template.

The provisional scope begins at the verified western route start around Fethiye/Ovacık/Ölüdeniz and hands off around Xanthos/Patara/Kınık. Spec 009 must define the exact pafta boundary; this wording is not an official-region claim.

## Existing Content to Reconcile

- `/likya-yolu-rotasi-oludenizden-kabak-koyuna/`
- `/likya-yolu-rotasi-kabak-koyundan-sidyma-antik-kentine/`
- `/likya-yolu-rotasi-sidymadan-karadereye/`
- `/likya-yolu-rotasi-karadereden-kinika/`
- matching daily journals 1–4;
- relevant portions of the 2014 route plan and actual 11-day itinerary;
- Fethiye/Ölüdeniz, Faralya, Kabak, Sidyma, Xanthos/Patara and nearby supporting articles where they genuinely add context.

Existing page boundaries must not be assumed to equal official pafta or modern practical-stage boundaries.

## Research Deliverables

For every official section in scope:

- official map source and sequence;
- start/end and branch relationships;
- source-qualified distance and elevation data where available;
- at least one legitimate GPS reference or an explicit `GPS coverage unavailable/unverified` state;
- terrain and effort interpretation;
- start/end access and practical exit options;
- accommodation mode categories;
- water/service observations with dates and sources;
- route-specific hazards and what requires a same-week check;
- related historical journal/article mapping.

Resolve and document contradictions rather than selecting the most convenient number.

## Authoring Deliverables

1. One ordered region overview with:
   - who this region suits;
   - defining terrain/logistics;
   - main seasonal limits;
   - how to enter/leave the region;
   - route branches;
   - all stage links.
2. One complete stage-guide record/page for every practical stage required to cover the official sections.
3. Short, original decision summaries for each stage.
4. Source and freshness records for all changing claims.
5. Links to matching first-hand pages, clearly labelled 2014.
6. Candidate combinations for the 3-, 5- and 7-day plan work in Spec 017; candidates are not published as recommendations until reviewed there.

## Content Style

- Lead with fit, effort and logistics; follow with scenery/history.
- Use concise paragraphs and labelled blocks, not a book-like wall of text.
- Explain local place names and branches once, then use consistent naming.
- State unknowns plainly.
- Keep historical anecdotes short on practical pages and link to the full journal.
- Never reproduce book prose, Ministry map artwork or third-party route descriptions.

## Responsive Requirements

- Region overview cards use the existing guide-section visual language.
- Mobile stage order follows geography, with no sideways map dependency.
- Long place names wrap; distance/source badges never overlap titles.
- Region overview images reuse suitable existing assets when they accurately represent the area; do not introduce generic scenery as evidence.

## Acceptance Criteria

1. Every official Western section from the verified boundary has a source-backed record and one-hop route to a practical stage guide.
2. Existing stage pages 1–4 are either upgraded in place or mapped to replacement coverage without broken canonical links.
3. Every stage has GPS coverage metadata, access/exit guidance, dated changing-condition fields and clear onward navigation.
4. No 2014 price, water, business or access statement is presented as current.
5. The region overview and all stages pass the shared template, source validation and responsive requirements.
6. Editorial reviewers can trace each factual route claim to the source registry.

## Out of Scope

- Final 3/5/7 recommendations.
- Central or Eastern guide prose.
- Republishing third-party GPS files or route-map art.
